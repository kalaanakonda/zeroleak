Why is showing you the code safe? Because the secrets aren't in the code. The paper is decided by three things — the nine officials' fragments (generated fresh at runtime), the drand beacon value (doesn't exist until unlock), and the seed derived from them at T-0. None is a constant anywhere below. Read every line and you learn exactly how it works and gain zero ability to predict a paper early. That's Kerckhoffs's principle: a real system is secure even when its design is public — only the key stays secret.
